# Prompts para ChatGPT Work

Estos prompts están diseñados para que Work opere sobre el repositorio con **contexto mínimo suficiente**, cambios pequeños y control de gasto cloud.

Orden recomendado:

1. `00_orchestrator.md` al iniciar una sesión extensa.
2. `01_feature_implementation.md` para implementar una tarea.
3. `02_azure_deployment.md` o `03_aws_deployment.md` solo al desplegar.
4. `04_integration_verification.md` al cerrar una fase.
5. `05_architecture_audit.md` cuando existan cambios grandes o inconsistencias.
